# Validation Library

## Overview

A small validation utility library.

## Functions

### validateEmail(email)

Checks whether an email contains a valid format.

**Parameters:**

- `email` (`string`) — the email address to validate.

**Returns:** `boolean` — `true` if the email has a valid format, otherwise `false`.

**Status:** Not yet implemented. This section documents the intended interface only; the sibling `validate.js` does not yet implement `validateEmail`.

Example:

```javascript
validateEmail("test@example.com")
```
